# 💻 Lab Experiments

This folder contains the **practical laboratory experiments** performed for **ITA1436 – Ethical Hacking**.

## 🧪 Experiments

The experiments involve hands-on practice with **Kali Linux**, Linux commands, and cybersecurity concepts.

Topics covered include:

- 🐧 Kali Linux commands
- 📂 File and directory management
- 📄 File viewing and editing commands
- 🌐 Networking commands
- 🔎 Information gathering
- 🛡️ Security tools and techniques
- 💻 Practical ethical hacking exercises

## 🛠️ Environment

- **Operating System:** Kali Linux
- **Terminal:** Linux Terminal
- **Tools:** Various cybersecurity and ethical hacking tools

## 🎯 Purpose

The purpose of these experiments is to gain practical knowledge of Linux, cybersecurity tools, and ethical hacking techniques in an authorized educational environment.
